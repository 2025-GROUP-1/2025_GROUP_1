Detailed Description

Represents a single CAD part in the application's tree model.

Each ModelPart is a node in the hierarchy displayed by the QTreeView. It stores per-column display data (part name and visibility) and owns a VTK pipeline — STL reader → poly-data mapper → actor — used to render the geometry in the 3D viewport. Colour defaults to white (255, 255, 255) and visibility defaults to true.
