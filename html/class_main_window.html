Detailed Description

Top-level application window.

Owns the QTreeView (populated from a ModelPartList), the VTK renderer and render window, and all toolbar/menu actions. Co-ordinates user interactions: STL file loading, per-part property editing via OptionDialog, and VTK render updates triggered by model changes.

On construction a default tree of 3 top-level parts, each with 5 children, is created as a placeholder until the user loads real STL files.

void MainWindow::updateRender ( )

Clears the renderer and re-adds actors for every part in the tree.

Removes all current actors, traverses the entire ModelPartList via updateRenderFromTree(), adds each non-null actor to the renderer, then calls Render() on the render window.
