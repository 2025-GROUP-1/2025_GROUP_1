Detailed Description

Qt tree model that manages the hierarchy of ModelPart nodes shown in the tree view.

Implements QAbstractItemModel so that a QTreeView can consume it directly. The tree always has exactly two columns: "Part" (column 0, the part name) and "Visible?" (column 1, showing "true" or "false"). An invisible root ModelPart acts as the column-header node; all user-visible items are its descendants.
